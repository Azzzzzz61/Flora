# 阶段计划

先验证顾客直接打开芙洛拉时的体验。进入首发渠道适配阶段后，再验证从微信分享打开同一家店的作品页。以下顺序是交接建议。时间、投入和试点规模由主理人后续决定。

| 阶段 | 交付什么 | 主理人怎么验收 |
| --- | --- | --- |
| 1 · 找准选花束的第一屏 | 参考截图和偏好记录。讨论看到哪些花、怎么往下逛、什么时候想筛选，再生成构图确实不同的单页稿。 | 打开样图，指出哪张最接近预期，以及想保留和改掉的具体部分。 |
| 2 · 验证选款体验 | 可点击的选款原型，使用有明显颜色、大小差异的样例花束。 | 自己选两个颜色，再选大小或用途，点进一款。看结果是否符合选择，是否看得懂如何咨询当地花店。 |
| 3 · 接上收花地与门店 | 演示选款咨询、按收花地找店、从分享直接进店三条路径。根据讨论结果确定接收询问、回复报价和档期的方式。 | 用一个与自己所在地不同的收花地发起测试。检查花店是否看到正确款式和需求，顾客是否找得到店家的回复。再从店主的分享入口直接看作品。 |
| 4 · 补全顾客端并试用 | 按已选风格完成逛花与我的。邀请愿意试用的店整理实拍作品，按实际需要安排管理端。 | 观察店主是否主动把作品页发给真实顾客，顾客能否带着具体款式来问。另记从平台发现店家的新询问，区分这两种价值。 |

每轮结束记录主理人确认的选择和仍然开放的问题。试点阶段优先观察真实使用。收费安排和各渠道的发布时间另行讨论。
