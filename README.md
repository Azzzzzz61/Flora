# 芙洛拉 Flora

芙洛拉是一款为顾客发现花束、联系本地精品花店而设计的独立移动应用。顾客可以发现精品花店的真实作品，按自己的喜好挑花束，把参考款发给收花地附近的店，商量能做成什么样。店主也可以把自己的作品页发给微信老顾客。

**设计与发布**　从第一版起，按独立 App 设计导航、页面和订花体验。微信小程序是计划优先尝试的发布渠道，店主可通过微信分享作品。

**当前进度**　项目处于产品和视觉探索阶段。顾客端底部四个入口已讨论形成，依次为 **逛花｜选花束｜找花店｜我的**。当前交付物为产品规划和视觉探索稿。交接基线为 2026 年 11 月 23 日。
