# 芙洛拉 Flora

芙洛拉是一款筹划中的微信小程序。顾客可以发现精品花店的真实作品，按自己的喜好挑花束，把参考款发给收花地附近的店，商量能做成什么样。店主也可以把自己的作品页发给微信老顾客。

**当前进度**　项目处于产品和视觉探索阶段。顾客端底部四个入口已讨论形成，依次为 **逛花｜选花束｜找花店｜我的**。本仓库的首次交接包含规划及探索稿，尚无可运行的小程序。交接基线为 2026 年 11 月 23 日。
