# 芙洛拉 Flora · 逐页高保真原型评审画板

本目录存放按五个固定底部入口（**逛花｜花店｜挑花｜消息｜我的**）逐页产出的高保真移动端 UI 原型，所有页面直接引用 [../design-system/tokens.css](../design-system/tokens.css)，离线双击即可在浏览器打开评审。

## 当前阶段工作约定

- **仅做浅色模式（暂不做深色模式）**：当前阶段暂不上线深色模式，已完成的「逛花」及后续待做的「花店｜挑花｜消息｜我的」与各二级页面均只设计与交付浅色模式（`design-system/` 中预留的深色变量保持不动，留待未来需要时启用）。
- **视觉基线**：纯白画廊 `#FFFFFF`、纯中性花束图底 `#F6F6F8`、默认春季樱雾粉紫顶部光晕（`#CFC8EA → #F3C8DC → #FFFFFF`）、浅色主按钮 `#0B051D` 配白字、柔粉 `#FFB3C7` 必配 `#0B051D` 墨字、等宽数字 `tabular-nums`。
- **端形态**：`390 × 844px` 微信小程序首发视口，顶部避让微信右上角胶囊，主入口配 `62px` 悬浮毛玻璃五项底栏。
